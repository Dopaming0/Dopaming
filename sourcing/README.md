## 1. 적용한 선별 프레임워크

### 1-1. 상위노출 공략 3레버 (요청하신 기준의 구조화)

신규 셀러가 판매량순 상위를 뚫는 경로는 사실상 셋뿐이고, 최소 하나는 성립해야 한다.

| 레버 | 성립 조건 | 왜 신규가 이기는가 |
|---|---|---|
| **P — 가격우위** | 상위 셀러 판가 대비 원가 30% 이상 낮게 사입 가능 | 상위 셀러가 국내 도매/위탁이면 중국 직사입이 원가에서 이긴다 |
| **R — 리뷰공백** | 1페이지 상품 리뷰가 대체로 300건 미만 | 리뷰 격차가 작으면 초기 30일 전환율로 역전 가능 |
| **T — 썸네일 중복** | 상위 상품 다수가 동일 1688 원본 이미지 사용 | 자체 촬영·연출 하나로 CTR을 갈라놓을 수 있다 |

셋 다 **현장에서만 검증된다.** 이 문서는 각 아이템에 대해 "어느 레버를 노려야 하는지"를 지정하고,
§4에서 그 레버가 실제로 열려 있는지 확인하는 절차를 준다.

### 1-2. 진입장벽 필터 — 왜 "장벽이 있는 것"만 골랐나

국내 위탁판매(도매매·오너클랜 등)는 사업자만 있으면 누구나 같은 상품을 등록한다.
그래서 위탁 상품은 **가격만 남는 싸움**이 되고, 신규가 이길 수 없다.
반대로 아래 장벽이 있는 카테고리는 위탁 셀러가 구조적으로 못 들어온다.

| 코드 | 장벽 | 위탁 셀러를 막는 이유 |
|---|---|---|
| `CERT-K` | 어린이제품 안전확인 (만 13세 이하) | 수입자 명의 KC 취득 필수. 시험비·리드타임이 진입 자체를 막는다 |
| `CERT-E` | 전기용품 안전확인/인증 | 모델별 시험 필요. 유효기간 5년, 수입자 명의로만 유효 |
| `CERT-R` | 방송통신기자재 적합성평가(전파) | 무선 기능 탑재 시 필수. 미인증 판매는 위법 |
| `FOOD` | 식품용기구·기구 수입신고(식약처) | 건별 수입신고 + 시험성적서. 위탁으로는 불가능 |
| `CERT-B` | 안전확인/공급자적합성(배터리·전열·운동기구 등) | 리튬배터리 포함 시 별도 확인 대상 |
| `CAPEX` | 초기 사입 자본 | 고단가 품목은 MOQ×단가가 진입 문턱 |
| `BULK` | 부피·중량 물류 | 보관·배송비가 위탁 구조로는 감당 안 됨 |
| `SKU` | 규격 분화 (차종·사이즈·호환) | 재고 SKU 관리 난이도 자체가 방어막 |
| `SEASON` | 시즌 선매입 | 비수기에 미리 사둘 자본과 배짱이 필요 |

⚠️ **장벽은 곧 법적 의무다.** `CERT-*`·`FOOD` 표시 품목은 인증/신고 없이 판매하면 위법이며,
통관 보류·판매 중지·과태료 대상이다. 인증 취득 비용과 기간(통상 2~8주, 품목당 수십만~수백만 원)을
반드시 손익에 넣고 계산할 것. 인증 비용은 아래 마진 계산에 **포함되어 있지 않다.**

## 2. 수요지수(DI)는 어떻게 만들었나

네이버 데이터랩 검색어 트렌드는 **호출마다 최댓값을 100으로 재정규화**하기 때문에,
서로 다른 호출의 숫자를 그대로 비교하면 틀린다. 그래서:

1. 28회 호출 전부에 **공통 앵커 키워드 `요가매트`**를 한 그룹으로 포함
2. 각 호출의 스케일 팩터 = `100 ÷ (해당 호출의 요가매트 2025-08 값)`
3. 모든 키워드 시계열에 팩터를 곱해 **단일 척도로 환산**

→ **DI = 요가매트 2025년 8월 검색량을 100으로 놓았을 때의 13개월 평균 상대 검색량**

| 파생 지표 | 정의 | 읽는 법 |
|---|---|---|
| `계절성` | 피크값 ÷ 평균 | 2.5 이상이면 시즌재. 재고 소진 실패 시 자본이 1년 묶임 |
| `모멘텀` | 최근 3개월 평균 ÷ 최초 3개월 평균 − 1 | 양수면 상승세. 단 계절재는 측정 시점 탓에 왜곡되니 피크월과 같이 볼 것 |
| `발주시점` | 피크월 − 2개월 | 해상운송 30~45일 + 통관·인증 리드타임 역산 |

전체 109개 시계열 원자료는 [`keyword-demand.csv`](./keyword-demand.csv)에 그대로 들어 있다.

## 3. 목표원가 계산식 — 이 문서의 핵심

"이 키워드로 마진 20%를 내려면 **1688에서 얼마 이하로 사야 하는가**"를 역산한 값이다.
1688 시세를 지어내는 대신, **합격선을 제시**한다. 실제 견적이 이 선을 넘으면 그 아이템은 탈락이다.

```
순매출     = 판가 ÷ 1.1                       (부가세 제외)
플랫폼수수료 = 판가 × (카테고리 수수료율 + 2.9%)   (기본수수료 + 결제수수료)
국내물류비  = 사이즈 등급별 고정               (S 2,800 / M 3,500 / L 5,500 / XL 9,000원)
부대비     = 순매출 × 5%                      (반품·불량·포장)

목표원가 상한 = 순매출 × (1 − 목표마진율 − 0.05) − 플랫폼수수료 − 국내물류비
```

여기서 **목표원가**는 국내 창고 입고 완료 시점의 개당 총원가다. 즉 아래를 전부 포함한다:

> 1688 단가 + 중국 내륙배송 + 국제운송(해상 LCL/항공) + 관세(대개 8%) + 통관·검사비 + 개당 인증 상각

**적용되지 않은 비용** — 별도로 반드시 계산할 것:
광고비(쿠팡 CPC), KC 인증 취득 초기비용, 재고 악성화 손실, 환율 변동, 창고 임대료.
실전에서는 광고비만으로 마진 5~10%p가 날아간다. **목표마진 30% 컬럼을 기준선으로 삼기를 권한다.**

**`배수` 읽는 법**: `판가 ÷ 목표원가`. 낮을수록 소싱이 쉽다.
- `2.0 이하` — 판가의 절반까지 지불 가능. 소싱 난이도 낮음
- `2.0~2.5` — 표준 구간
- `2.5 초과` — 판가의 40% 미만으로 사야 함. 저단가 품목에서 고정 물류비가 마진을 먹는 구조 (해당 14개)

## 4. 현장 검증 프로토콜 — 이걸 안 하면 이 문서는 무용지물

S티어 20개에 대해 **아이템당 30분**, 아래 6단계를 순서대로 돌린다.
3단계에서 탈락하면 즉시 다음 아이템으로 넘어간다.

| 단계 | 확인 | 통과 기준 | 탈락 시 |
|---|---|---|---|
| **1. 리뷰공백** | 쿠팡에서 키워드 검색 → 판매량순 정렬 → 1페이지 상위 10개 리뷰수 기록 | 중앙값 **300건 미만** | 리뷰 격차가 이미 해자. 탈락 |
| **2. 썸네일 중복** | 상위 10개 썸네일을 구글 이미지 역검색 | **3개 이상이 동일 1688 원본** | 이미 자체 촬영으로 정리된 시장. T레버 불가 |
| **3. 가격 헤드룸** | 1페이지 최저가 기록 → 본 문서의 목표원가(마진30%)와 비교 | 최저가 ≥ 목표원가 × 2.5 | 가격 경쟁 불가. 탈락 |
| **4. 1688 실견적** | 1688/알리바바에서 동일 사양 3개 공급사 견적 (MOQ 포함) | 견적가 ≤ **목표원가 × 0.55** (운송·관세 여유분) | 소싱 원가 미달. 탈락 |
| **5. 인증 확인** | 본 문서 `필수인증` 컬럼 → 시험기관(KTL·KTC 등) 견적 | 취득비 ÷ 초도물량 ≤ 판가의 3% | 인증비가 마진을 먹음. 물량 상향 또는 탈락 |
| **6. 발주 타이밍** | 본 문서 `발주시점` 컬럼과 현재 월 대조 | 발주월 ±1개월 이내 | 다음 사이클로 이연 (시즌재는 늦으면 재고 폭탄) |

**6단계를 모두 통과한 아이템만 샘플 발주한다.** 샘플 없이 대량 발주하지 말 것.

### 초기 30일 운영 (상위노출 실전)

1. 상품명 = **메인 키워드 1개 + 서브 3~5개**. 중복·과장 수식어 제거
2. 카테고리 정확도가 노출의 전제. 잘못 넣으면 어떤 최적화도 안 먹힌다
3. 썸네일은 **자체 촬영**. §4-2에서 확보한 "다들 같은 사진 쓰는 시장"이 여기서 수익이 된다
4. 초기 7~14일 클릭률·전환율이 랭킹을 고정시킨다. 이 구간에만 광고를 집중
5. **가구매·리뷰 조작은 하지 말 것** — 적발 시 판매 정지이고, 애초에 이 문서의 전제(정상 전환율로 이기기)와 상충한다

## 6. 재현 방법

수요 데이터는 네이버 데이터랩 검색어 트렌드 API로 수집했다. 재현하려면:

1. 키워드를 4개씩 묶고, **모든 호출에 앵커 `요가매트`를 5번째 그룹으로 추가**
2. `timeUnit=month`, 13개월 구간으로 호출
3. 각 응답에서 `100 ÷ 앵커의 첫 달 값`을 팩터로 구해 전 계열에 곱함
4. 13개월 평균이 DI

판가를 실제 시세로 교체하면 §3 계산식이 목표원가를 그대로 다시 뱉는다. 그게 이 문서의 사용법이다.
