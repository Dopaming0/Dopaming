## 운영 대시보드

`../admin.html` — 리뷰어 DB·캠페인·선정 스코어링·검수 체크리스트·등급 자동화를 담은 브라우저 대시보드.
브라우저에서 파일을 열면 바로 동작하며(localStorage 저장), `07` CSV와 가져오기/내보내기로 호환된다. 정기 백업은 JSON 내보내기 사용.

## 절대 원칙 (요약)

1. **모든 리뷰에 대가표시** — "업체로부터 제품(서비스)을 제공받아 작성한 후기입니다"를 본문에 명확히 표기. 누락 시 발행 반려.
2. **별점·내용 보장 금지** — 계약서, 광고, 상담 어디에서도 "5점 보장", "상위노출 보장" 문구를 쓰지 않는다.
3. **구매평 캠페인 금지** — 쿠팡·스마트스토어 등 커머스 구매평(상품평)에 대가를 지급하는 캠페인은 수주하지 않는다. 커머스 광고주는 블로그 키워드 리뷰 또는 플랫폼 공식 체험단 세팅 대행으로 안내한다.
4. **원고료 지급 시 3.3% 원천징수** — 사업소득 처리 후 홈택스 신고, 지급명세서 제출.
