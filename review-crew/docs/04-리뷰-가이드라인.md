### 📌 필수 조건 (미충족 시 수정 요청됩니다)

1. **대가표시 (가장 중요!)**

   > 이 리뷰는 [업체명]으로부터 제품(서비스)을 제공받아 작성되었습니다.
2. **제목**: 지정 키워드 「[키워드]」를 제목에 자연스럽게 포함
3. **본문**: [1,000]자 이상, 지정 키워드 본문 [3]회 내외 자연스럽게 사용
4. **사진**: 직접 촬영한 사진 [15]장 이상 (스크린샷·제공 이미지 제외)
5. **마감**: [발행 마감일]까지 발행 후, 오픈채팅/폼으로 URL 제출

### 💡 잘 쓰는 팁 (선택)

- 첫 사진은 가장 잘 나온 대표컷으로 — 검색 썸네일이 됩니다.
- 방문형: 외관 → 내부 → 메뉴판 → 음식 → 총평 순서가 읽기 편해요.
- 좋았던 점 2~3가지 + 아쉬운 점 1가지를 솔직하게. 진짜 후기처럼 읽히는 글이 검색에서도 오래 살아남아요.
- 위치·주차·영업시간 등 정보성 내용을 넣으면 조회수가 오래갑니다. (방문형은 지도 첨부 권장)

### 🚫 하지 말아 주세요

- 다른 리뷰 글 복사·짜깁기 (유사문서로 검색 누락)
- 체험하지 않은 내용, 과장·허위 표현 ("최고", "인생 맛집"을 강요하지 않아요 — 느낀 만큼만!)
- 발행 후 6개월 내 삭제·비공개 전환
