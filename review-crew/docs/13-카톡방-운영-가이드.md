# 13. 카톡방 운영 가이드 (운영 허브 = 카카오톡 채팅방)

리뷰밋의 일상 운영은 **카카오톡 채팅방**에서 돌아간다. 이 문서는 지인 10명 방에서 시작해 오픈채팅으로 확장하기까지, 방을 운영 허브로 쓰는 방법을 정리한다.

## 1. 대원칙 — 방에서 하는 것 / 하지 않는 것

| 카톡방에서 한다 | 카톡방에서 하지 않는다 |
|---|---|
| 캠페인 모집 공지 (06-템플릿 1번) | ❌ **개인정보 수집** — 주소·연락처·계좌를 방에 올리게 하지 않는다 (전원에게 노출됨). 반드시 구글폼 또는 1:1로 |
| 선정 발표 (이름만, 상세는 1:1) | ❌ **신청 접수를 채팅으로** — "저요!" 댓글은 DB가 안 된다. 신청은 폼 링크로 |
| 마감 리마인드 전체 공지 | ❌ 개별 독촉·검수 지적을 방에서 공개적으로 — 반드시 1:1 (공개 지적은 방 분위기와 리텐션을 죽인다) |
| 발행 후기 공유·칭찬 (이달의 리뷰어) | ❌ 광고주 정보·대행료 얘기 |
| Q&A, 리뷰 팁 공유 | ❌ 별점·긍정 후기 유도 발언 — "솔직하게 써주세요"가 공식 톤 |

**기록 원칙**: 카톡 대화는 흘러가면 끝이다. 선정·배송·제출·검수 상태는 대화가 아니라 **admin.html(또는 구글시트)에 즉시 기록**한다. "방에서 말했으니 됐지"가 사고의 시작.

## 2. 방 구조 — 단계별

### 1단계 (지금): 지인 10명 방 하나
- 지금 있는 방을 그대로 **운영방**으로 쓴다. 방 이름을 "리뷰밋 체험단 1기"로 바꿔 소속감을 만든다.
- **공지 기능 고정**: ① 신청폼 링크 ② 리뷰 가이드라인(04) 요약 ③ 대가표시 문구 원문. 새 멤버가 들어와도 공지만 보면 되게.
- 운영자(본인)가 공지 올리는 시간대를 고정한다(예: 월요일 오전 10시 캠페인 공지) — 예측 가능해야 열어본다.

### 2단계 (풀 30명~): 공지방 / 수다방 분리
- 사람이 늘면 공지가 수다에 묻힌다. **공지 전용 방**(운영자만 발언, 캠페인 공지·발표만)과 **커뮤니티 방**(자유 대화)으로 분리.
- 이때부터 신규 유입은 **오픈채팅**으로 받는 것을 권장 — 일반 단톡방 초대는 전화번호·프로필 노출 문제가 있다. 오픈채팅은 익명 프로필이 가능해 리뷰어 모집에 더 적합하고, 검색 노출(방 이름 "체험단")로 모집 채널도 된다 (09-플레이북 3절).

### 3단계 (풀 100명~): 카카오톡 채널 병행
- 전체 공지는 카카오톡 채널(구 플러스친구) 메시지로, 커뮤니티는 오픈채팅으로 역할 분리. 알림톡 자동화(11-가이드 5절)는 이 단계에서 검토.

## 3. 캠페인 한 사이클 — 카톡방 기준 실행 순서

1. **공지 (D-14, 방)**: 06-템플릿 1번 + 신청폼 링크. 공지로 고정.
2. **신청 (폼)**: 방에서는 "신청은 폼으로!"만 안내. 댓글 신청은 정중히 폼으로 유도.
3. **선정 발표 (D-10)**: 방에는 "○○님, ○○님 선정!"까지만. 배송지 수집·서약서·가이드는 **선정자 1:1 채팅**으로 (06-템플릿 2번).
4. **진행 (1:1 + 대시보드)**: 배송·URL 제출·검수는 1:1로 주고받고, 상태는 admin.html 진행 보드에 기록.
5. **리마인드**: 마감 D-2 전체 공지(방) 1회 + 미제출자 1:1 (admin.html 홈의 [리마인드 문안 복사] 활용).
6. **마무리 (방)**: 완료 공지 + 잘 쓴 리뷰 1~2건 링크 공유(작성자 칭찬) → 다음 캠페인 기대감으로 연결.

## 4. 카톡 기능 활용 팁

### 투표 기능 — 쓸 곳과 쓰면 안 되는 곳

투표는 **수요 파악·일정 조율용**이지, 신청·진행의 공식 기록이 될 수 없다. 투표 결과에는 채널 URL도, 개인정보 동의도, 타임스탬프 내보내기도 없다.

| 용도 | 판단 | 방법 |
|---|---|---|
| 캠페인 **참여 의향 1차 조사** | ✅ 적합 | "이번 주 ○○ 캠페인 관심 있으신 분?" 투표 → 관심자 수를 보고 모집 인원·공고 확정 → **정식 신청은 폼 링크로** |
| 다음 캠페인 카테고리 선호 조사 | ✅ 적합 | 뷰티 vs 식품 vs 리빙 복수 투표 |
| 밋업·발표 일정 조율 | ✅ 적합 | 날짜 보기 투표 |
| 진행 상황 셀프 체크 | ⚠️ 보조로만 | "제품 수령하신 분 투표해 주세요" — 수령 현황을 한눈에 보는 용도로는 유용. 단, **공식 기록은 여전히 대시보드/시트**에 옮겨 적는다 (투표는 지워지고, 누가 안 눌렀는지 추적이 안 됨) |
| **정식 신청 접수** | ❌ 부적합 | 채널 정보·동의 수집 불가 → 반드시 폼 |
| **리뷰 완료 보고** | ❌ 부적합 | URL 제출이 핵심인데 투표엔 URL이 없다 → URL 제출 폼 또는 1:1 |

권장 조합: **투표(의향) → 폼(신청·URL 제출) → 대시보드(기록)**. 투표로 문턱을 낮추고, 데이터는 폼으로 받는다.

- **투표 외 팁**: 참여감을 만드는 가장 싼 도구가 투표다. 캠페인마다 1개씩은 걸어라.
- **공지 + 캘린더**: 캠페인 마감일을 톡캘린더에 등록해 방에 공유하면 리마인드가 반자동.
- **1:1 오픈채팅 링크**: 문의 동선을 "방이 아닌 1:1"로 몰기 위해 프로필/공지에 1:1 링크 고정 (09-플레이북 8절 방 규칙 템플릿 참고).
- **지도·샵검색 공유 금지 예외**: 방문형 캠페인은 매장 카카오맵 링크를 공지에 포함.

## 5. 운영자 일일 루틴 (카톡 기준, 하루 10분)

- 아침: admin.html 홈 "오늘 할 일" 확인 → 마감 임박자 1:1 리마인드 발송
- 낮: 방 Q&A 응답, 신규 폼 신청 확인 → 채널 감사 → 승인 시 D0 웰컴 1:1 (09-플레이북 4절)
- 저녁: URL 제출분 검수 → 대시보드 기록 → 통과자에게 1:1 감사 메시지
