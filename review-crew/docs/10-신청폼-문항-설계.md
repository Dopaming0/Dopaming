## 자동 스크리닝 기준 (폼 응답 확인 시, 수요일 루틴)

응답 시트의 "상태" 열에 결과를 기록한다. 순서대로 판정:

| 판정 | 조건 | 처리 |
|---|---|---|
| **즉시 반려** | ① 1-1 개인정보 동의 거부(분기 종료 응답) ② 채널 URL 무효(접속 불가·형식 오류·타인 채널) | 반려 메시지 발송 후 종결. 재신청은 언제든 가능함을 안내 |
| **보류** | 3-6 최근 30일 발행 수 "0건" | 보류 메시지 발송 — "최근 포스팅 1건 발행 후 다시 신청" 안내. 응답은 시트에 보관 |
| **승인 (감사 진행)** | 위에 해당 없음 | 아래 채널 감사 5항목 진행 → 통과 시 DB 등록 + D0 웰컴 |

반려 메시지:

```
[신청자명]님, 리뷰밋 리뷰어 신청 확인했습니다.
아쉽지만 이번에는 [사유: 채널 주소가 확인되지 않아] 승인이 어려웠어요 🥲
채널 주소를 확인하신 뒤 언제든 다시 신청해 주세요: [폼 링크]
```

보류 메시지:

```
[신청자명]님, 리뷰밋 신청 감사합니다!
다만 최근 30일 내 발행 글이 없어 이번엔 승인을 보류했어요.
자유 주제 포스팅 1건만 올리신 뒤 다시 신청해 주시면
바로 재검토해 드릴게요 🙂 [폼 링크]
```

## 승인 후 채널 감사 체크리스트 (5항목, 항목당 1분)

스크리닝 통과자에 한해 진행. **5항목 모두 통과 시에만 DB 등록.**

- [ ] **1. 실존 채널** — URL 접속 확인, 프로필·닉네임이 신청 정보와 일치하는지. 의심스러우면 "채널 프로필에 임시 문구 한 줄" 요청으로 본인 소유 확인
- [ ] **2. 최근 30일 활동** — 30일 내 발행 1건 이상 실제 존재 (자기 신고 3-6과 대조, 큰 차이 나면 메모)
- [ ] **3. 사진 품질** — 최근 글 3건 기준 직접 촬영 사진 사용, 초점·밝기·구도가 리뷰에 쓸 수준인지
- [ ] **4. 유사문서/펌글 여부** — 본문 한 문단을 네이버·구글에 검색해 복붙 여부 확인, 이미지 출처 불명 글 반복 여부
- [ ] **5. 광고성 도배 여부** — 최근 글 대부분(체감 70% 이상)이 대가성 리뷰로만 채워져 있는지 (검색 노출·신뢰도 저하 채널)

판정:

- 5항목 통과 → DB 등록(ID 부여) + 응답 시트 상태 "승인" + **당일 D0 웰컴 발송** (`09-플레이북` 4절)
- 3·4·5번 미달 → 반려 (사유는 완곡하게: "채널 방향이 이번 모집과 맞지 않아")
- 1·2번 미달 → 보류 (보완 안내 후 재신청 유도)
- 감사 소견은 응답 시트 "감사 메모" 열과 DB 메모 컬럼에 남긴다 — 선정 스코어링의 카테고리 적합도 수동 조정(0~25) 근거가 된다
