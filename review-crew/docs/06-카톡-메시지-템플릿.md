# 06. 카톡 메시지 템플릿 모음 (듀얼 트랙 고도화 버전)

> [ ] 부분을 채워 그대로 발송. 1:1 지인 카톡 메시지 및 오픈채팅방 공지사항 전용.

---

## 📌 [트랙 1] 지인 대상 1:1 카카오톡 메시지 (고품질 실배송 리뷰 확보)

> **핵심 톤앤매너**: 영업 톤을 완전히 빼고, 미안함과 고마움이 담긴 자연스럽고 따뜻한 말투. 아이폰 기본 카메라, 햇빛 자연광 컷 유도.

```text
안녕! 이번에 진행하는 [상품명, ex: 아이스 홍시] 런칭 때문에 리뷰 테스터를 소소하게 구하고 있어서 연락했어! 😊
맛있는 제품 무료로 보내줄 테니, 편하게 먹어보고 솔직한 리뷰 하나만 부탁해도 될까?

[진행 방법]
1. 아래 검색어로 들어가서 1분 정도 둘러보고 '찜' 누른 후 구매!
   👉 지정 검색어: [검색어 입력]
2. 나한테 [주문번호 / 환불받을 계좌 / 결제금액] 톡으로 남겨주기! (확인하는 대로 바로 송금해 줄게!)

[리뷰 가이드 📸]
제품 받으면 리뷰 부탁할게! 사진은 너무 각 잡고 찍을 필요 없이, 햇빛 자연스럽게 들어오는 곳에서 아이폰 기본 카메라 느낌으로 무심한 듯 찍어주면 제일 좋아. (살짝 흠집이 보이거나 포장이 뜯겨 있어도 리얼해서 더 좋으니까 편하게 찍어줘!)

진행 가능하면 편하게 톡 줘! 너무 고마워!! ❤️
```

## 📌 [트랙 2] 오픈채팅방 상단 고정 공지사항 (대규모 자동화 관리)

> **핵심 톤앤매너**: 명확한 텍스트 구분선과 이모지를 사용하되, 딱딱하지 않고 신뢰감을 주는 커뮤니티 공지 톤앤매너.

```text
📢 [공지] 오늘자 체험단/리뷰 참여 가이드 (상시 업데이트)

안녕하세요! 현재 두 가지 형태의 캠페인을 진행 중입니다. 원하시는 방식을 선택하여 가이드에 맞춰 진행해 주세요.

🔹 TYPE A: 실배송 체험단 (제품 무료 제공 + 추가 리워드 [O원])
* 조건: 수령 후 5일 내 포토+텍스트 리뷰 작성 (정성스러운 사진 필수)
* 진행: [지정 검색어] 검색 ➔ 2분 체류 및 상품 찜 ➔ 구매

🔹 TYPE B: 빈박스 리뷰 (리워드 [O원] / 빠른 정산)
* 조건: 배송 완료 후 별점 5개만 쿨하게 남기기 (텍스트 불필요)
* 진행: [지정 검색어] 검색 ➔ 1분 체류 및 상품 찜 ➔ 구매

──────────────────
✅ [필수] 구매 후 인증 폼 작성 (여기로 제출해 주셔야 정산이 처리됩니다!)
👉 폼 링크: [구글 폼 단축 URL 삽입 - ex: bit.ly/오늘의캠페인]
(제출 서류: 검색 화면 캡쳐, 상품 찜 캡쳐, 주문 내역 캡쳐)

⚠️ 주의사항 (필독)
* 다계정 참여 시 반드시 네트워크(Wi-Fi ↔ 데이터) 및 기기를 변경해 주세요. 동일 IP 연속 구매 시 정산이 거절될 수 있습니다.
* 광고(AD) 표시된 상품을 클릭하시면 안 됩니다.

기타 문의사항은 언제든 편하게 남겨주세요.
- 담당자 [이름] 드림
```

## 💡 고도화 운영 팁 & 자동화 가이드

### 1. Drip-Feeding (리뷰 등록 속도 분산)
- 지인(실배송)과 오픈채팅방(빈박스) 참여자가 같은 날 수십 개의 리뷰를 올리면 알고리즘 어뷰징으로 적발될 수 있습니다.
- 폼 신청 시 "리뷰 작성 권장일"을 일별 2~3개씩 지정하여 자연스럽게 우상향으로 적재되도록 트래픽을 분산시킵니다.

### 2. 구글 폼 세팅 최적화 (칼퇴근 시스템)
- 구글 폼 첫 번째 질문을 **"참여 유형 선택 (실배송 / 빈박스)"**으로 설정합니다.
- 관리 시트에서 '빈박스' 필터만 걸어 별점 5개 확인 후 엑셀 대량 송금 파일로 10분 만에 정산 완료할 수 있습니다.

## 기타 운영 카톡 메시지

### 3) 캠페인 모집 공지
```
📦 [○○ 핸드크림] 배송형 체험단 모집 (5명)

🎁 제공: ○○ 핸드크림 정품 (○○원 상당) 무료 배송
📅 리뷰 마감: 제품 수령 후 7일 이내
✍️ 미션: 네이버 블로그 리뷰 1건
   · 제목 키워드: [키워드]
   · 사진 15장↑ / 1,000자↑ / 대가표시 필수
⏰ 신청 마감: [날짜] 밤 11시
🎯 발표: [날짜] 개별 연락 (선정 시 배송지 수집)

👉 신청하기: [구글폼 링크]
```

### 4) 검수 수정 요청
```
[리뷰어명]님, 리뷰 잘 봤습니다! 딱 한 가지만 보완 부탁드려요.
❗ [수정 항목: 대가표시 문구 추가 등]
수정 후 이 채팅으로 알려주시면 바로 확인할게요 🙂
```
