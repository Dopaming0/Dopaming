# 06. 카톡 메시지 템플릿 모음

> [ ] 부분을 채워 그대로 발송. 오픈채팅 공지·카카오톡 채널 메시지 겸용.

---

## 1) 캠페인 모집 공지

```
📦 [○○ 핸드크림] 배송형 체험단 모집 (5명)

🎁 제공: ○○ 핸드크림 정품 (○○원 상당) 무료 배송
📅 리뷰 마감: 제품 수령 후 7일 이내
✍️ 미션: 네이버 블로그 리뷰 1건
   · 제목 키워드: [키워드]
   · 사진 15장↑ / 1,000자↑ / 대가표시 필수
⏰ 신청 마감: [날짜] 밤 11시
🎯 발표: [날짜] 개별 연락 (선정 시 배송지 수집)

👉 신청하기: [구글폼 링크]

* 리뷰 내용과 평가는 자유! 솔직 후기 환영해요.
* 제공받은 제품은 재판매할 수 없어요.
```

## 2) 선정 안내 (개별)

```
[리뷰어명]님, 축하드려요 🎉
[캠페인명] 체험단에 선정되셨습니다!

진행 안내
1️⃣ 서약서 확인·동의: [링크]
2️⃣ 방문 예약: [예약 방법 — "리뷰밋 체험단"이라고 말씀해 주세요]
3️⃣ 가이드라인: [링크] (대가표시 문구 꼭 확인!)
4️⃣ 발행 마감: 체험일로부터 7일 이내
5️⃣ URL 제출: [폼 링크]

궁금한 건 언제든 이 채팅으로 주세요 🙂
```

## 3) 미선정 안내 (개별)

```
[리뷰어명]님, 이번 [캠페인명]은 모집 인원이 적어
아쉽게 함께하지 못하게 되었어요 🥲
신청 이력은 남아 있어서 다음 캠페인 선정 시 우선 반영됩니다.
새 캠페인 소식 곧 전해드릴게요!
```

## 4) 발행 리마인드 (마감 D-2)

```
[리뷰어명]님, [캠페인명] 리뷰 마감이 이틀 남았어요 ⏰
마감: [날짜]
가이드라인: [링크]
어려운 점 있으시면 미리 말씀 주세요. 조율 가능해요!
```

## 5) 최종 독촉 (마감일)

```
[리뷰어명]님, 오늘이 [캠페인명] 리뷰 마감일이에요.
오늘까지 발행이 어려우시면 꼭 회신 부탁드립니다.
회신 없이 미발행 시 서약서에 따라 다음 선정이 제한될 수 있어요 🙏
```

## 6) 검수 수정 요청

```
[리뷰어명]님, 리뷰 잘 봤습니다! 딱 한 가지만 보완 부탁드려요.
❗ [수정 항목: 예) 대가표시 문구가 빠져 있어요. 본문 하단에 아래 문구를 추가해 주세요.]
> 이 리뷰는 [업체명]으로부터 제품(서비스)을 제공받아 작성되었습니다.
수정 후 이 채팅으로 알려주시면 바로 확인할게요 🙂
```

## 7) 캠페인 완료 감사

```
[리뷰어명]님, [캠페인명] 참여 감사합니다 💐
정성스러운 리뷰 덕분에 캠페인이 잘 마무리됐어요.
이행 기록이 반영되어 다음 캠페인 선정 확률이 올라갑니다.
다음 소식으로 또 만나요!
```

## 8) 광고주 결과 보고 발송

```
사장님, 안녕하세요. 리뷰밋입니다 🙂
[캠페인명] 체험단이 마무리되어 결과 리포트 보내드립니다. (첨부)
✔ 발행 리뷰 [5]건 — URL 목록 리포트 참조
✔ "[키워드]" 검색 시 블로그 탭 [순위] 노출
✔ 리뷰어 공통 피드백 요약 (제품 개선 참고용)
다음 달 그로스 패키지(매월 8인 + 키워드 로테이션) 진행 여부는
편하실 때 말씀 주세요. 감사합니다!
```
