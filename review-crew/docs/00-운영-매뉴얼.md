## Part 3. 리스크 관리 수칙

1. 대가표시 누락 리뷰는 **발행 승인 금지**. 이미 발행됐다면 즉시 수정 요청.
2. 광고주가 "별점 보장", "나쁜 내용 삭제"를 요구하면: 계약서 제4조를 근거로 거절. 반복 시 계약 해지.
3. 구매평(쿠팡·스마트스토어 상품평) 대가 지급 요청은 **수주 금지** — 표시광고법 위반 + 업무방해. 대안으로 블로그 키워드 리뷰 또는 플랫폼 공식 체험단 세팅 대행을 제안.
4. 리뷰어 개인정보(주소·연락처)는 캠페인 종료 후 목적 달성 시 파기 원칙, 동의받은 보관 기간 준수.
5. 원고료 현금 지급 금지 — 반드시 계좌이체 + 원천징수 + 지급 대장.
