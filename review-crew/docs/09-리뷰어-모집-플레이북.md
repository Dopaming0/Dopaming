# 09. 리뷰어 모집 플레이북 (10명 → 100명)

목표: 90일 내 **활성 리뷰어 100명** (캠페인당 5~8명을 카테고리·품질 맞춰 선정하려면 풀 100명이 필요).
원칙: **머릿수보다 이행률.** 마감을 지키고 검수를 통과하는 리뷰어 30명이, 유령 300명보다 낫다.

---

## 1단계. 시드 10명 → 추천 네트워크 (1~2주)

지인 10명은 리뷰어이자 **모집 노드**다.

- [ ] 10명 전원 채널 감사 후 DB 등록 (`07-리뷰어-DB-양식.csv`)
- [ ] **친구 추천제 가동**: 추천으로 들어온 리뷰어가 첫 캠페인을 완주하면 추천인에게 보상 (다음 캠페인 우선 선정권 또는 소정의 추천비). 체험단 리뷰어의 최대 유입 경로는 현업에서도 "하는 친구 따라서"다.
- [ ] 10명에게 부탁할 것 딱 하나: "블로그·인스타 하는 지인 2명씩만 소개" → 이론상 +20명

## 2단계. 상시 유입 채널 구축 (2~4주, 이후 상시)

우선순위 순:

1. **카카오 오픈채팅방** — "리뷰밋 체험단 모집방" 개설. 오픈채팅 검색에 "체험단"으로 노출되도록 방 이름·태그 세팅. 공지에 랜딩페이지·신청폼 고정. *모집과 운영(공지·독촉)이 한곳에서 되는 핵심 채널.*
2. **네이버 블로그 공식 계정** — 캠페인 모집 공고를 매번 블로그 글로도 발행. 블로거들은 "체험단 모집", "○○ 체험단"을 네이버에서 검색해서 찾아온다. 공고 글 자체가 SEO 모집 채널.
3. **인스타그램 계정** — 모집 공고 카드뉴스 + 해시태그(#체험단 #체험단모집 #블로그체험단 #서포터즈모집). 선정 리뷰어의 후기를 리그램하면 신뢰 자산이 쌓인다.
4. **네이버 카페** — 체험단·리뷰어 모임 카페, 지역맘카페(뷰티·육아·생활용품 캠페인과 궁합)에 모집 공고. *각 카페 홍보 규정 준수 — 무단 도배는 계정 정지로 모집 채널을 잃는다.*
5. **당근마켓 동네생활** (지역 캠페인 한정) — 지역 기반 모집에 의외로 반응 좋음.

## 3단계. 첫 캠페인을 모집 콘텐츠로 (상시)

- 캠페인 결과(리뷰어의 실제 발행 글)를 "이런 제품을 이렇게 받아요" 사례로 인스타·블로그에 재가공 → 다음 모집의 신뢰 자료
- 모집 공고에는 반드시: 제공 내역의 **정가**, 미션 난이도, 선정 기준. 투명할수록 지원 질이 올라간다
- 미선정자 관리가 곧 모집이다: 미선정 안내 + "다음 선정 우선 반영"으로 풀 이탈 방지 (`06-카톡-메시지-템플릿.md` 3번)

## 4단계. 유지·등급제 (풀 50명부터)

| 등급 | 기준 | 혜택 |
|---|---|---|
| A (에이스) | 이행률 100% + 검수 1회 통과 3회 이상 | 신규 캠페인 우선 선정, 원고료 캠페인 배정 |
| B (일반) | 이행률 80%↑ | 일반 선정 |
| C (주의) | 미이행 1회 또는 노쇼 1회 | 선정 보류, 소명 후 복귀 |
| 제외 | 미이행 2회 누적 | 풀 제외 |

- 월 1회 "이달의 리뷰어" 선정(우수 리뷰 소개 + 소정 상품) — 비용 대비 리텐션 효과가 가장 크다
- 분기 1회 휴면(90일 무참여) 리뷰어 재활성 메시지 → 무응답 시 DB 휴면 처리

## 하지 말 것

- ❌ 리뷰어 모집 대행업체에서 명단 구매 — 유령·중복 계정 비율이 높고 개인정보 출처가 불투명
- ❌ "무조건 선정" 남발 — 품질 미달 리뷰가 광고주 신뢰를 깎는다. 모집이 아쉬워도 선정 기준은 유지
- ❌ 오픈채팅방에서 타 업체 방 이용자 무단 스카웃(DM 도배) — 신고 누적 시 방 자체가 제재

## 주간 운영 루틴 (모집 담당 기준, 주 3시간)

- 월: 이번 주 캠페인 공고 발행 (오픈채팅 + 블로그 + 인스타 동시)
- 수: 신규 지원자 채널 감사 → DB 등록 → 웰컴 메시지
- 금: 이행률·등급 업데이트, 미선정자·휴면 관리 메시지
