# 09. 리뷰어 모집 플레이북 (10명 → 100명)

목표: 90일 내 **활성 리뷰어 100명** (캠페인당 5~8명을 카테고리·품질 맞춰 선정하려면 풀 100명이 필요).
원칙: **머릿수보다 이행률.** 마감을 지키고 검수를 통과하는 리뷰어 30명이, 유령 300명보다 낫다.

관련 문서: 신청 폼 문항·스크리닝 기준은 `10-신청폼-문항-설계.md`, 메시지 원문은 `06-카톡-메시지-템플릿.md`, DB 양식은 `07-리뷰어-DB-양식.csv`.

---

## 1. 모집 퍼널 — 단계 정의·목표 전환율·측정 위치

모집은 "신청자 수"가 아니라 **퍼널 전체**로 관리한다. 병목이 어디인지 모르면 채널만 늘리게 된다.

| # | 단계 | 정의 | 목표 전환율 | 측정 위치 |
|---|---|---|---|---|
| 1 | 유입 | 공고를 보고 신청폼 링크 클릭 또는 오픈챗 입장 | — (주간 유입 자체를 집계) | 채널별 단축링크 클릭 수 + 신청폼 "지원 경로" 문항 (구글시트 폼 응답 탭) |
| 2 | 신청 | 구글폼 제출 완료 | 유입 대비 30~50% | 구글시트 폼 응답 탭 행 수 (주간) |
| 3 | 승인 | 자동 스크리닝 + 채널 감사 통과 → DB 등록 | 신청 대비 60~70% | `07-리뷰어-DB-양식.csv` 주간 신규 등록 수 |
| 4 | 온보딩 완료 | 승인 후 7일 내 오픈챗 입장 + 첫 캠페인 신청 | 승인 대비 80% | 온보딩 체크 시트 (구글시트, D0/D1/D3/D7 열) |
| 5 | 첫 캠페인 완주 | 첫 선정 캠페인 발행 + 검수 통과 | 온보딩 완료 대비 70% | DB의 참여캠페인수 ≥1 & 이행률 100% (admin.html 대시보드) |
| 6 | 활성 | 첫 완주 후 90일 내 재참여 | 첫 완주 대비 60% | admin.html 대시보드 (마지막 참여일 기준) |

주간 신규 신청 15건이면 → 승인 ~10명 → 온보딩 ~8명 → 첫 완주 ~5명. 12주면 시드 포함 100명 풀이 만들어지는 산수다.

### 병목별 처방

| 병목 | 증상 | 처방 |
|---|---|---|
| 유입 → 신청 낮음 | 링크 클릭은 되는데 제출이 없음 | 공고에 제공 내역 **정가**·미션 난이도·선정 기준 명시(투명성), 폼 문항 수 축소(10-문서 기준 유지), 신청 마감 시한 명시 |
| 신청 → 승인 낮음 | 반려·보류가 많음 | 공고에 지원 자격(운영 중인 블로그/인스타 필수, 최근 30일 발행 이력) 선명하게 → 애초에 미달자 유입 감소 |
| 승인 → 온보딩 낮음 | 승인 후 잠수 | D0 웰컴을 승인 **당일** 발송(아래 온보딩 시퀀스), 오픈챗 초대를 웰컴 메시지 안에 포함 |
| 온보딩 → 첫 완주 낮음 | 첫 캠페인에서 미이행 | 첫 캠페인은 난이도 낮은 배송형으로 배정, 발행 D-2 리마인드 철저(06-템플릿 4번) |
| 첫 완주 → 활성 낮음 | 한 번 하고 이탈 | 완료 감사 메시지(06-템플릿 7번) + 다음 캠페인 우선 안내, 이달의 리뷰어 이벤트(아래 8절) |

## 2. 시드 10명 → 추천 네트워크 (1~2주)

지인 10명은 리뷰어이자 **모집 노드**다.

- [ ] 10명 전원 채널 감사 후 DB 등록 (`07-리뷰어-DB-양식.csv`)
- [ ] **친구 추천제 가동**: 추천으로 들어온 리뷰어가 첫 캠페인을 완주하면 추천인에게 보상 (다음 캠페인 우선 선정권 또는 소정의 추천비). 체험단 리뷰어의 최대 유입 경로는 현업에서도 "하는 친구 따라서"다.
- [ ] 10명에게 부탁할 것 딱 하나: "블로그·인스타 하는 지인 2명씩만 소개" → 이론상 +20명
- [ ] 추천 유입은 신청폼 "지원 경로" 문항에 추천인 성명을 받게 해서 보상 지급 근거를 남긴다

## 3. 상시 유입 채널 구축 (2~4주, 이후 상시)

우선순위 순:

1. **카카오 오픈채팅방** — "리뷰밋 체험단 모집방" 개설. 오픈채팅 검색에 "체험단"으로 노출되도록 방 이름·태그 세팅. 공지에 랜딩페이지·신청폼 고정. *모집과 운영(공지·독촉)이 한곳에서 되는 핵심 채널.*
2. **네이버 블로그 공식 계정** — 캠페인 모집 공고를 매번 블로그 글로도 발행. 블로거들은 "체험단 모집", "○○ 체험단"을 네이버에서 검색해서 찾아온다. 공고 글 자체가 SEO 모집 채널.
3. **인스타그램 계정** — 모집 공고 카드뉴스 + 해시태그(#체험단 #체험단모집 #블로그체험단 #서포터즈모집). 선정 리뷰어의 후기를 리그램하면 신뢰 자산이 쌓인다.
4. **네이버 카페** — 체험단·리뷰어 모임 카페, 지역맘카페(뷰티·육아·생활용품 캠페인과 궁합)에 모집 공고. *각 카페 홍보 규정 준수 — 무단 도배는 계정 정지로 모집 채널을 잃는다.*
5. **당근마켓** (지역 캠페인 한정) — 지역 기반 모집에 의외로 반응 좋음. *당근 운영정책 준수 — 상업적 모집 공고는 일반 동네생활 글이 아니라 비즈니스 프로필·동네홍보 등 공식 기능으로만 게시한다.*

### 채널별 주간 목표·비용·리드타임

| 채널 | 주간 목표(신규 신청) | 비용 | 리드타임(공고→유입) | 운영 포인트 |
|---|---|---|---|---|
| 오픈채팅 | 3~5명 | 0원 | 즉시~3일 | 방 이름·태그 검색 최적화, 공지 고정 |
| 블로그 공고(SEO) | 2~4명 | 0원 | 1~2주 (검색 노출까지) | 공고마다 발행, 제목에 "○○ 체험단 모집" |
| 인스타그램 | 1~3명 | 0원 (부스팅 시 회당 1~3만) | 3~7일 | 카드뉴스 + 해시태그, 후기 리그램 |
| 맘카페 등 네이버 카페 | 1~2명 | 0원 (유료 홍보 게시판은 건당 1~5만) | 등업 1~2주 + 게시 후 3~7일 | 카페별 홍보 규정 숙지, 도배 금지 |
| 당근 (공식 기능) | 0~2명 (지역 캠페인 시) | 0원 (동네홍보 유료 시 별도) | 1~3일 | 지역 방문형 전용 · 비즈니스 프로필 등 공식 기능만 사용 |
| 친구 추천제 | 1~2명 | 추천 보상 (우선 선정권 또는 5천~1만 원) | 즉시 | 완주 확인 후 보상 지급, 폼에 추천인 기입 |

합계 주 8~18명 신청 → 퍼널 목표(주 15건)와 맞는다. 2주 연속 미달 채널은 운영 포인트부터 점검.

## 4. 온보딩 시퀀스 (승인 후 7일)

승인만 하고 방치하면 절반이 첫 캠페인 전에 증발한다. 승인일 = D0으로 아래를 기계적으로 돌린다. 진행 여부는 온보딩 체크 시트(구글시트)에 D0/D1/D3/D7 열로 기록.

> **발송 범위 주의**: D0 웰컴은 승인 절차 안내이므로 전원 발송 가능. 그러나 **D1·D3·D7의 캠페인 권유·넛지는 광고성 정보에 해당하므로 마케팅 수신 동의자에게만 1:1 발송**한다. 미동의자는 본인이 입장한 오픈채팅방 공지로만 캠페인 소식을 접하게 한다 (하단 "하지 말 것"의 원칙과 동일 기준).

### D0 — 웰컴 메시지 + 오픈챗 초대 (필수)

```
[리뷰어명]님, 리뷰밋 리뷰어 승인을 축하드려요 🎉
채널 확인 결과 함께하게 되었습니다!

📌 딱 두 가지만 해주세요
1️⃣ 리뷰어 오픈채팅방 입장: [오픈챗 링크]
   (캠페인 공지가 모두 이곳에 올라와요)
2️⃣ 리뷰 가이드라인 1분 훑어보기: [04-가이드라인 링크]
   특히 "대가표시 문구"는 모든 리뷰에 필수예요.

새 캠페인이 열리면 방에서 바로 안내드릴게요 🙂
```

### D1 — 예비 미션 안내 (선택)

품질 사전 확인용. 강제 아님 — 완료 시 첫 선정에서 참고(카테고리 적합도 수동 조정 근거).

```
[리뷰어명]님, 가벼운 제안 하나 드려요 🙂
첫 캠페인 전에 본인 채널에 자유 주제 포스팅 1건을
올려주시면(일상·후기 무엇이든 OK) 채널 스타일을 미리 볼 수 있어
첫 선정 때 참고가 됩니다. 부담은 전혀 없으셔도 돼요!
올리셨다면 URL만 이 채팅으로 회신해 주세요.
```

### D3 — 첫 캠페인 신청 안내

```
[리뷰어명]님, 지금 신청 가능한 캠페인이 있어요 📦
[캠페인명] — 제공: [제공 내역] ([정가]원 상당)
신청 마감: [날짜] / 발표: [날짜]
👉 신청하기: [링크]
첫 캠페인은 신규 리뷰어분들이 우선 검토됩니다. 편하게 도전해 보세요!
```

### D7 — 미신청자 넛지 (D7까지 캠페인 신청 이력 없을 때만)

```
[리뷰어명]님, 승인 후 일주일이 지났는데
아직 캠페인 신청 전이시네요 🙂
어려운 점이 있으신가요? (신청 방법, 일정, 카테고리 등)
답장 주시면 맞는 캠페인을 골라 안내드릴게요.
이번 주 캠페인 보기: [링크]
```

D7 넛지에도 무응답이면 추가 발송 없이 대기 — 다음 신규 캠페인 공지 때 자연 복귀를 기다린다.

## 5. 첫 캠페인을 모집 콘텐츠로 (상시)

- 캠페인 결과(리뷰어의 실제 발행 글)를 "이런 제품을 이렇게 받아요" 사례로 인스타·블로그에 재가공 → 다음 모집의 신뢰 자료
- 모집 공고에는 반드시: 제공 내역의 **정가**, 미션 난이도, 선정 기준. 투명할수록 지원 질이 올라간다
- 미선정자 관리가 곧 모집이다: 미선정 안내 + "다음 선정 우선 반영"으로 풀 이탈 방지 (`06-카톡-메시지-템플릿.md` 3번)

## 6. 등급제 (풀 50명부터)

| 등급 | 기준 | 선정 처리 | 혜택 |
|---|---|---|---|
| A (에이스) | 캠페인 완주 3회 이상 **그리고** 이행률 100% | 정상 선정 | 신규 캠페인 우선 안내, 원고료 캠페인 배정 |
| B (일반) | 이행률 80% 이상 | 정상 선정 | 일반 선정 |
| C (주의) | 미이행 또는 노쇼 1회 | **자동 보류 표시** (운영자 수동 해제 가능) | 소명 후 복귀 |
| 제외 | 미이행 2회 누적 | 선정 불가 | — |
| 휴면 | 90일 무참여 | 재활성 시퀀스 대상 (아래 7절) | 복귀 시 등급 복원 |

- 등급 산정과 선정 점수는 **단일 기준**으로 운영한다 — 신청자 선정 시 스코어링(채널 규모 30 + 카테고리 적합도 25 + 이행 신뢰도 30 + 활동성 15)은 admin.html이 자동 계산. 동점이면 신규 리뷰어 우선(풀 성장 목적).
- 신규(참여 이력 0회)는 이행 신뢰도 기본 15점으로 기회를 준다 — "신규라 뽑히지 않는" 죽은 풀을 방지.

## 7. 휴면 재활성 시퀀스

활동성 점수는 마지막 참여일 기준 30일 이내 15점 / 90일 이내 10점 / 그 외 5점으로 떨어진다. 90일이 넘기 **전에** 개입한다.

### 60일 무참여 — 부드러운 안부 (경고 아님, 경고 톤 금지)

```
[리뷰어명]님, 리뷰밋이에요 🙂
요즘 캠페인에서 못 뵌 것 같아 안부 겸 연락드려요.
바쁘신 시즌이면 전혀 부담 갖지 마시고요!
혹시 원하는 카테고리 캠페인이 없어서였다면 알려주세요.
[주력카테고리] 캠페인이 들어오면 먼저 안내드릴게요.
이번 주 캠페인 보기: [링크]
```

### 90일 무참여 — 휴면 전환 안내

DB 등급을 `휴면`으로 변경하고, 마케팅 수신 동의자에 한해 발송.

```
[리뷰어명]님, 마지막 참여 후 90일이 지나
리뷰어 풀에서 휴면 상태로 전환됩니다.
휴면이어도 기록은 그대로 보관되고,
캠페인 1회만 다시 참여하시면 바로 복귀돼요 🙂
돌아오고 싶으실 때 언제든: [신규 캠페인 링크]
```

### 분기 1회 — 재활성 캠페인 초대

분기마다 진입 장벽이 낮은 배송형 캠페인 1건을 "컴백 캠페인"으로 지정해 휴면 리뷰어에게 우선 안내.

```
[리뷰어명]님, 오랜만이에요! 리뷰밋 컴백 캠페인 소식 💌
[캠페인명] — 제공: [제공 내역] ([정가]원 상당)
이번 캠페인은 쉬고 계셨던 리뷰어분들을 우선 검토합니다.
부담 없는 배송형이라 복귀에 딱이에요.
👉 신청: [링크] (마감 [날짜])
```
