# 트렌드 관측소

터진 영상(기획 레퍼런스·국내 농산물 채널)과 한국보다 유행이 먼저 도는 나라의 인기 급상승 영상을 한 화면에서 보고, 다음 영상 기획 재료를 찾는 도구입니다. 본 사이트와 같은 GitHub Pages에서 `/trends/` 경로로 열립니다. 모든 영상 카드에는 제목 밑에 **2~3줄 내용 요약**이 붙습니다(외국어 영상은 한국어 제목도).

| 탭 | 보는 것 |
|---|---|
| 오늘 | 들어오자마자 볼 것만: 이번 주 Claude 브리핑, 최근 터진 영상 6개, 해외에서 먼저 뜨는 영상 4개, 지금 먹히는 제목 공식 3줄 |
| 벤치마크 | 레퍼런스 34곳 + 농산물 유튜브 100곳의 영상. 이팔청춘·농산물·챌린지·인터뷰로 묶어 보고, 제목·요약·채널로 검색합니다. 기본은 최근 90일 동안 채널 평소의 3배 이상 터진 영상. 채널 목록(인스타그램·자동 발굴 후보 포함)은 맨 아래에 접혀 있습니다 |
| 해외 트렌드 | '한국에 아직 없는 영상'(선행국 차트에는 있고 한국 차트에는 없음)과 12개국 '나라별 차트' |
| 인사이트 | 어떤 제목 패턴·길이·업로드 시간·단어가 잘 터지는지 문장으로. **제목 점검기**에 쓰려는 제목을 넣으면 먹히는 패턴과 빠진 패턴을 바로 알려 줍니다 |
| 내 채널 | `my_channels.json`에 넣은 내 채널의 최근 영상 50개. 벤치마크에서 먹힌 제목 패턴을 내가 쓰고 있는지 성적표(써볼 만함·잘 쓰는 중·줄여볼 것)로 |
| 저장 | 카드의 ☆로 모은 영상. 한 줄 메모를 적고 요약과 함께 마크다운으로 복사 (이 브라우저에만 저장) |

Claude 앱 안에서 열면 두 가지가 더 켜집니다(보는 사람의 Claude 사용량을 씁니다). 인사이트 탭의 **Claude 분석**은 훅 공식과 채널별 기획 아이디어를 주고, 카드마다 있는 **아이디어** 버튼은 그 영상이 왜 먹혔는지와 이팔청춘·농산물·챌린지 버전을 줍니다.

폰에서는 탭이 화면 아래 막대로 내려가고, 카드는 썸네일 옆에 제목, 아래에 요약이 오는 가로형으로 바뀝니다.

## 국가 구성

- **선행국** 미국·영국·일본·캐나다·호주: 숏폼 포맷과 밈이 한국보다 먼저 퍼지는 시장
- **글로벌** 독일·프랑스·브라질·멕시코·인도·인도네시아: 카테고리 비교용
- **기준** 한국: '한국 미상륙' 판정 기준

국가는 `collect.py`의 `REGIONS`에서 바꿉니다.

## 자동 갱신 켜기

지금 들어 있는 `data/*.json`은 2026-10-03~05에 모은 시드 데이터입니다. 요약(`summaries.json`)은 화면에 기본으로 보이는 영상 154개에만 들어 있고, 영상 설명만 보고 쓴 것이라 66개에 '추정' 표시가 붙어 있습니다. 아래 설정을 마치면 매일 새벽 자동으로 갱신됩니다.

1. Google Cloud Console에서 **YouTube Data API v3**를 사용 설정하고 API 키를 발급합니다. 키는 'API 제한사항 → YouTube Data API v3'로만 제한합니다.
2. GitHub 저장소 **Settings → Secrets and variables → Actions**에서 `YOUTUBE_API_KEY` 시크릿을 추가합니다.
3. **Actions → Collect YouTube Trends → Run workflow**로 첫 실행을 합니다.
4. (선택) 영상 요약과 주간 브리핑을 받으려면 `ANTHROPIC_API_KEY` 시크릿을 추가합니다. 아래 '영상 요약'을 보세요.
5. (선택) 인스타그램 지표까지 받으려면 아래 '인스타그램 연결'을 마치고 `IG_USER_ID`, `IG_ACCESS_TOKEN` 시크릿을 추가합니다.

이후 매일 05:47 KST에 `trends.yml`이 실행되어 데이터를 `trends-data` 브랜치에 올리고, `pages.yml`이 그 데이터로 페이지를 다시 배포합니다. 데이터 커밋이 main 히스토리에 쌓이지 않습니다.

로컬 실행:

```bash
YOUTUBE_API_KEY=... python3 trends/collect.py            # 전체
YOUTUBE_API_KEY=... python3 trends/collect.py --only farm --no-discover
YOUTUBE_API_KEY=... python3 trends/collect.py --only refs   # 레퍼런스 채널만
npx http-server -p 8080                                   # http://localhost:8080/trends/
```

1회 실행 쿼터는 약 2,400 units에 영상 요약분(새 영상 수만큼)을 더한 값으로, 기본 한도 10,000의 3분의 1 안쪽입니다.

| 항목 | 호출 | units |
|---|---|---|
| 인기 차트 | 12개국 × (전체 + 카테고리 15) | ≈ 190 |
| 쇼츠 | 12개국 × `#shorts` 검색 (48시간 내 조회순) | 1,200 |
| 농산물 채널 | 100채널 × (업로드 목록 + 영상 통계) | ≈ 200 |
| 채널 발굴 | 키워드 8개 × 채널 검색 | 800 |
| 레퍼런스 채널 | 34채널 × (업로드 목록 + 영상 통계) | ≈ 70 |
| 영상 요약 | 새 영상 × 인기 댓글 1 + 설명 50개당 1 (첫날 최대 600개, 이후 하루 100~300개) | ≈ 100~600 |

## 지표

- **평소의 N배**: 영상 조회수 ÷ 그 채널 최근 업로드 중 **같은 형식**(쇼츠 3분 이하 / 롱폼) 영상 조회수의 중앙값(레퍼런스는 최근 30개, 농산물은 최근 15개). 3배 이상을 '터진 영상'으로 봅니다. 쇼츠와 롱폼은 조회수 단위가 달라서 섞으면 롱폼이 늘 터진 것처럼 보입니다. 한 형식이 3개 미만이면 비워 둡니다
- **한국 미상륙**: 같은 수집 시점 한국 차트(전체·쇼츠·카테고리)에 없는 영상
- **시간당 조회**: 해외 차트는 조회수 ÷ 업로드 후 경과 시간, 벤치마크는 (오늘 조회수 − 어제 스냅샷 조회수) ÷ 두 수집 사이 시간. 벤치마크 쪽은 두 번째 자동 수집부터 '지금 오르는 순' 정렬과 오늘 탭에 쓰입니다
- **인스타그램 배수**: 게시물 반응(좋아요 + 댓글) ÷ 그 계정 최근 15개 게시물 반응의 중앙값. 좋아요를 숨긴 게시물은 댓글만 셉니다

## 영상 요약

매일 수집 뒤 `summarize.py`가 아직 요약이 없는 영상만 골라 요약합니다. 터진 영상, 한국 미상륙 영상, 내 채널 영상을 먼저 합니다.

- **입력**: 제목, 설명(링크 제거, 1,200자), 태그, 인기 댓글 8개(YouTube Data API). 자막은 클라우드 IP에서 YouTube가 막아 쓰지 않습니다.
- **출력**: 2~3문장 요약(무슨 일이 벌어지는지 → 댓글에서 보인 반응), 외국어 영상의 한국어 제목, 근거가 부족할 때의 '추정' 표시. `data/summaries.json`에 쌓이고, 데이터에서 빠진 영상의 요약은 지웁니다.
- **모델**: CLAUDE.md 정책의 '대량 저난이도 배치'에 따라 `claude-haiku-4-5`를 **Message Batches API**(50% 할인)로 부릅니다. 영상 15개를 요청 하나로 묶고, JSON 스키마 출력으로 받습니다. 배치는 최대 15분 기다리고, 그 안에 안 끝나면 배치 ID를 저장해 다음 날 실행에서 결과를 가져옵니다.
- **비용**: 영상당 입력 약 1,100토큰·출력 약 150토큰. 배치 할인 기준 첫 채움(약 1,600개)에 1.5달러 안팎, 이후 하루 0.1~0.3달러 수준입니다.
- **실패 처리**: 한도 초과·거절·잘림·형식 오류가 난 묶음은 버리고 다음 실행에서 다시 합니다. 수집과 데이터 게시는 멈추지 않습니다.
- **주간 브리핑과 연결**: `digest.py`와 Claude 분석은 터진 영상의 제목과 함께 이 요약을 근거로 씁니다.

```bash
YOUTUBE_API_KEY=... ANTHROPIC_API_KEY=... python3 trends/summarize.py           # 배치
YOUTUBE_API_KEY=... ANTHROPIC_API_KEY=... python3 trends/summarize.py --sync    # 바로 호출(로컬 확인용)
python3 trends/summarize.py --dry-run                                          # 요약할 영상 목록만
```

## 인사이트를 뽑는 방식

1. **측정**: 영상마다 채널 평소 대비 배수(x)와 시간당 조회 증가(vph)를 수집기에서 계산합니다.
2. **패턴**: 인사이트 탭이 브라우저에서 바로 집계합니다. 비용이 들지 않고 매일 자동으로 바뀝니다.
   - **제목 공식**: 돈·금액, 나이·세대, 말 인용, 질문형, 대결·비교, 최초·극단, 경고·부정, 기간·도전 등 12개 패턴. **같은 채널 안에서** 패턴이 있는 영상과 없는 영상의 터질 확률을 비교합니다. 채널마다 제목 습관이 달라서(예: 매출 숫자를 늘 쓰는 채널) 섞어 비교하면 왜곡되기 때문입니다. 양쪽 모두 8개 이상일 때만 보여 주고, 두 비율 차이의 z 값으로 신뢰도(높음 2 이상 · 보통 1.3 이상)를 붙입니다.
   - **길이·업로드 요일·시간대(한국 시간)·단어**: 범위 전체의 터질 확률과 비교합니다. 단어는 채널 두 곳 이상에서 5번 넘게 나오고 3번 이상 터진 것만 셉니다.
3. **해석**: Claude 앱 안에서 대시보드를 열면 'Claude 분석' 버튼이 보입니다. 위 통계와 터진 영상·덜 나온 영상의 제목·요약을 보내 훅 공식, 이팔청춘·농산물·챌린지 기획 아이디어(A가 B한다 + 썸네일 문구), 피할 것을 받습니다. 보는 사람의 Claude 사용량을 쓰고, 결과는 이 브라우저에 7일 보관합니다. GitHub Pages에서는 버튼이 보이지 않습니다.
4. **주간 요약**: 매일 수집 뒤 `digest.py`가 돌다가 지난 요약이 6일을 넘으면 새로 만듭니다(Actions에서 '주간 인사이트 요약을 지금 새로 만들기'를 체크하면 바로). 이번 주 업로드 중 터진 영상, 지금 오르는 영상, 범위별 제목 공식을 정리하고, `ANTHROPIC_API_KEY` 시크릿이 있으면 Claude가 헤드라인·발견·채널별 기획 아이디어·다음 주 체크포인트를 붙입니다. 결과는 오늘 탭 맨 위와 저장소의 '📈 주간 인사이트' 이슈 댓글로 옵니다(이슈를 구독하면 GitHub 알림).
5. **검증**: 쓰려는 제목은 인사이트 탭의 제목 점검기로 미리 확인하고, 아이디어는 '메모'로 기획 노트에 옮긴 뒤, 만든 영상의 결과로 가설을 확인합니다. 숫자는 상관관계라서 원인을 말해 주지 않습니다.

## Claude 설정

| 설정 | 위치 | 기본값 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Settings → Secrets → Actions | 없으면 영상 요약은 건너뛰고 주간 요약은 통계만 |
| `SUMMARY_MODEL` | Settings → Variables → Actions | `claude-haiku-4-5` (CLAUDE.md 정책: 대량 저난이도 배치) |
| `DIGEST_MODEL` | Settings → Variables → Actions | `claude-opus-4-8` (CLAUDE.md 정책: 요약은 Opus 4.8) |
| `DIGEST_ISSUE` | Settings → Variables → Actions | 비워 두면 이슈 댓글을 남김, `0`이면 남기지 않음 |

주간 요약은 적응형 사고(`thinking: adaptive`) + `effort: high` + JSON 스키마 출력으로 한 주에 한 번 보냅니다. 실패하면(한도 초과·거절·연결 오류) 그 주는 통계만 남기고 데이터 게시는 계속됩니다.

## 내 채널 등록

`my_channels.json`의 `channels`에 한 줄씩 넣습니다. 다음 수집부터 '내 채널' 탭이 채워집니다.

```json
{"id": "UC...", "title": "이팔청춘", "note": "16~32세 인터뷰"}
```

## 레퍼런스 채널 목록 관리

`ref_channels.json`에 한 줄씩 추가합니다.

```json
{"id": "UC...", "title": "채널명", "group": "참여형", "market": "US", "src": "13강", "note": "왜 지켜보는지 한 줄"}
```

- `group`: `솔파`(스튜디오 솔파 채널), `참여형`(일반인 참여 게임·대화·실험), `인터뷰`, `챌린지`, `이팔청춘`(10대~30대 초반 인터뷰·인사이트) 중 하나. 설명은 같은 파일의 `groups`에 있습니다
- `market`: 국기 표시용 국가 코드
- `src`: 강의에서 언급된 회차. 강의 밖에서 추가한 채널은 빈 문자열로 둡니다

## 인스타그램 연결 (선택)

인스타그램은 남의 계정 지표를 주는 공개 API가 없습니다. 공식 Instagram Graph API의 **비즈니스 디스커버리**만 다른 계정의 팔로워·게시물 수·게시물별 좋아요·댓글을 줍니다. 조건은 이렇습니다.

- 내 인스타그램 계정이 **프로페셔널(비즈니스 또는 크리에이터)** 계정이고 페이스북 페이지에 연결돼 있어야 합니다.
- 조회 대상도 비즈니스·크리에이터 계정이어야 합니다. 개인 계정은 '조회 불가'로 표시됩니다.
- 릴스 조회수는 주지 않습니다. 그래서 반응(좋아요 + 댓글)을 계정 평소와 비교합니다.

설정 순서:

1. [Meta for Developers](https://developers.facebook.com/)에서 비즈니스 유형 앱을 만들고 'Instagram Graph API'(페이스북 로그인 방식)를 추가합니다.
2. 권한 `instagram_basic`, `pages_show_list`, `pages_read_engagement`, `business_management`로 사용자 토큰을 받습니다. 만료가 없는 **비즈니스 관리자 시스템 사용자 토큰**을 쓰면 매일 수집이 끊기지 않습니다. 일반 장기 토큰은 60일마다 갱신해야 합니다.
3. `GET /me/accounts`로 페이지 ID를, `GET /{page-id}?fields=instagram_business_account`로 내 인스타그램 계정 ID를 확인합니다.
4. 저장소 시크릿에 `IG_USER_ID`(3의 ID)와 `IG_ACCESS_TOKEN`(2의 토큰)을 넣습니다.

연결 전에는 `farm_instagram.json`의 `seed.followers`(2026-10-03 웹 검색에 보인 값)를 `*` 표시와 함께 보여 줍니다.

계정은 `farm_instagram.json`에 한 줄씩 추가합니다.

```json
{"handle": "아이디", "name": "표시 이름", "tags": ["유통"], "note": "한 줄 설명"}
```

## 농산물 채널 목록 관리

`farm_channels.json`에 한 줄씩 추가합니다. 수집기가 구독자·조회수·최근 영상을 매일 채웁니다.

```json
{"id": "UC...", "title": "채널명", "tags": ["재배", "직판"], "crops": "사과", "region": "경북 청송", "note": "한 줄 설명"}
```

`tags` 값은 `재배`(직접 농사), `직판`(농부 직거래), `유통`(과일가게·플랫폼·생협·위탁판매), `시장`(도매시장·경매), `리뷰`(리뷰·큐레이션), `정보`(교육·기업), `미디어`(농업 언론·방송), `브이로그`, `기관` 중에서 고릅니다. 인스타그램 계정도 같은 태그를 씁니다. 수집기는 `FARM_KEYWORDS`로 새 채널도 검색해서 벤치마크 탭 맨 아래 채널 목록의 '새로 찾은 후보'에 보여 줍니다. 후보를 확인한 뒤 위 형식으로 옮기면 됩니다.

## 한계

- Instagram은 농산물 계정만 비즈니스 디스커버리로 받습니다. 남의 릴스 조회수는 API로 받을 수 없어 반응으로 비교합니다. TikTok은 Research API가 학술용이라 넣지 않았습니다.
- YouTube `mostPopular` 차트는 롱폼 위주입니다. 쇼츠는 `#shorts` 검색으로 보강하지만 공식 쇼츠 차트는 아닙니다.
- 시드 데이터에는 쇼츠 검색 결과, 일부 채널의 구독자 수와 영상 길이가 없습니다. 첫 자동 수집 뒤부터 채워집니다.
- 요약은 설명·태그·댓글로 쓰므로 영상 안에서만 나오는 내용은 빠질 수 있습니다. 설명이 빈약한 쇼츠는 '추정'이 많습니다.
