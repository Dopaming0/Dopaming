# 해외 트렌드 관측소

한국보다 유행이 먼저 도는 나라의 YouTube 인기 급상승 영상, 기획 레퍼런스 채널, 국내 농업·과일 판매 채널을 한 화면에서 보는 벤치마킹 도구입니다. 본 사이트와 같은 GitHub Pages에서 `/trends/` 경로로 열립니다.

| 탭 | 보는 것 |
|---|---|
| 국가별 | 12개국 인기 급상승 차트. 순위, 시간당 조회, 구독자 대비 조회, 좋아요율로 정렬 |
| 카테고리별 | 전 국가를 합친 카테고리별 영상. 여러 나라에 동시에 뜬 영상이 위로 |
| 선행 신호 | 선행국 차트에는 있지만 한국 차트에는 아직 없는 영상 |
| 레퍼런스 채널 | 강의에 나온 채널과 챌린지·사회실험 채널 16곳에서 평소보다 터진 영상. '메모 복사'로 링크 + 한 줄 메모 줄을 노트에 붙여 넣기 |
| 국내 농업 채널 | 직접 농사·과일 판매·유통 채널 70개 + 채널 평소보다 터진 영상 |

## 국가 구성

- **선행국** 미국·영국·일본·캐나다·호주: 숏폼 포맷과 밈이 한국보다 먼저 퍼지는 시장
- **글로벌** 독일·프랑스·브라질·멕시코·인도·인도네시아: 카테고리 비교용
- **기준** 한국: '한국 미상륙' 판정 기준

국가는 `collect.py`의 `REGIONS`에서 바꿉니다.

## 자동 갱신 켜기

지금 들어 있는 `data/*.json`(latest·farm·refs)은 2026-10-03에 수집한 시드 데이터입니다. 아래 설정을 마치면 매일 새벽 자동으로 갱신됩니다.

1. Google Cloud Console에서 **YouTube Data API v3**를 사용 설정하고 API 키를 발급합니다. 키는 'API 제한사항 → YouTube Data API v3'로만 제한합니다.
2. GitHub 저장소 **Settings → Secrets and variables → Actions**에서 `YOUTUBE_API_KEY` 시크릿을 추가합니다.
3. **Actions → Collect YouTube Trends → Run workflow**로 첫 실행을 합니다.

이후 매일 05:47 KST에 `trends.yml`이 실행되어 데이터를 `trends-data` 브랜치에 올리고, `pages.yml`이 그 데이터로 페이지를 다시 배포합니다. 데이터 커밋이 main 히스토리에 쌓이지 않습니다.

로컬 실행:

```bash
YOUTUBE_API_KEY=... python3 trends/collect.py            # 전체
YOUTUBE_API_KEY=... python3 trends/collect.py --only farm --no-discover
YOUTUBE_API_KEY=... python3 trends/collect.py --only refs   # 레퍼런스 채널만
npx http-server -p 8080                                   # http://localhost:8080/trends/
```

1회 실행 쿼터는 약 2,400 units로, 기본 한도 10,000의 4분의 1 정도입니다.

| 항목 | 호출 | units |
|---|---|---|
| 인기 차트 | 12개국 × (전체 + 카테고리 15) | ≈ 190 |
| 쇼츠 | 12개국 × `#shorts` 검색 (48시간 내 조회순) | 1,200 |
| 농업 채널 | 70채널 × (업로드 목록 + 영상 통계) | ≈ 140 |
| 채널 발굴 | 키워드 8개 × 채널 검색 | 800 |
| 레퍼런스 채널 | 16채널 × (업로드 목록 + 영상 통계) | ≈ 35 |

## 지표

- **시간당 조회**: 조회수 ÷ 업로드 후 경과 시간(수집 시각 기준)
- **구독자 대비**: 조회수 ÷ 채널 구독자 수. 1배 이상이면 구독자 밖으로 퍼진 영상
- **한국 미상륙**: 같은 수집 시점 한국 차트(전체·쇼츠·카테고리)에 없는 영상
- **NEW / ▲n**: 직전 수집 대비 새로 진입했거나 순위가 오른 영상
- **농업 채널 배수**: 영상 조회수 ÷ 그 채널 최근 15개 업로드 조회수의 중앙값. 3배 이상을 '터진 영상'으로 봅니다
- **레퍼런스 배수**: 영상 조회수 ÷ 그 채널 최근 30개 업로드 중 **같은 형식**(쇼츠 3분 이하 / 롱폼) 영상 조회수의 중앙값. 쇼츠와 롱폼은 조회수 단위가 달라서 섞으면 롱폼이 늘 터진 것처럼 보입니다. 한 형식이 3개 미만이면 배수를 비워 둡니다
- **댓글/천회**: 조회 1,000회당 댓글 수. 의견이 갈리는 영상일수록 높습니다

## 레퍼런스 채널 목록 관리

`ref_channels.json`에 한 줄씩 추가합니다.

```json
{"id": "UC...", "title": "채널명", "group": "참여형", "market": "US", "src": "13강", "note": "왜 지켜보는지 한 줄"}
```

- `group`: `솔파`(스튜디오 솔파 채널), `참여형`(일반인 참여 게임·대화·실험), `인터뷰`, `챌린지` 중 하나. 설명은 같은 파일의 `groups`에 있습니다
- `market`: 국기 표시용 국가 코드
- `src`: 강의에서 언급된 회차. 강의 밖에서 추가한 채널은 빈 문자열로 둡니다

## 농업 채널 목록 관리

`farm_channels.json`에 한 줄씩 추가합니다. 수집기가 구독자·조회수·최근 영상을 매일 채웁니다.

```json
{"id": "UC...", "title": "채널명", "tags": ["재배", "직판"], "crops": "사과", "region": "경북 청송", "note": "한 줄 설명"}
```

`tags` 값은 `재배`(직접 농사), `직판`(농부 직거래), `유통`(과일가게·도매·플랫폼), `정보`(교육·기업·미디어), `브이로그`, `기관` 중에서 고릅니다. 수집기는 `FARM_KEYWORDS`로 새 채널도 검색해서 페이지 하단 '자동 발굴 후보'에 보여 줍니다. 후보를 확인한 뒤 위 형식으로 옮기면 됩니다.

## 한계

- Instagram 릴스와 TikTok은 넣지 않았습니다. Instagram은 Graph API로 남의 계정 조회수를 받을 수 없고, TikTok Research API는 학술용입니다.
- YouTube `mostPopular` 차트는 롱폼 위주입니다. 쇼츠는 `#shorts` 검색으로 보강하지만 공식 쇼츠 차트는 아닙니다.
- 시드 데이터에는 쇼츠 검색 결과와 채널 구독자 수가 없습니다. 첫 자동 수집 뒤부터 채워집니다.
